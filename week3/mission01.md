동기와 비동기는 코드가 실행되는 순서에 따른 방식이다. 동기는 도미노처럼 앞에 작업이 진행된 뒤 뒤에 작업이 진행되는 방식이며 비동기는 골드버그 장치처럼 어떤 한 작업이 진행되면서 다른 작업이 동시에 진행되는 방식이다. 인터넷에서 데이터를 가져오는 작업과 같이 시간이 오래걸리는 작업에는 비동기가 훨씬 효율적이다.
이때 작업이 순차적이지 않고 동시다발적으로 이루어지기 위해서는 함수자체를 인자처럼 호출할 수 있는 콜백함수가 필요하다. 다시말해, 콜백함수를 통해 시간순대로가 아닌 방식으로 작업을 진행할 수 있다. 하지만 콜백함수는 가독성이 나쁘고 에러의 처리가 곤란하다. 이러한 문제점을 해결하기 위해 Promise를 도입했다. Promise(객체)는 resolve와 reject와 같은 콜백함수를 인자로 전달받는다. 함수내에서 객체를 생성하고 내부에서 비동기 처리의 결과에 따른 메소드를 호출한다. 그리고 이 결과를 후속 처리 메소드로 전달한다. 흔히 성공, 실패를 각각 then과 catch라는 메소드로 전달한다.
하지만 이때도 비동기함수자체가 많아지면 코드가 복잡해질 수 있다. 이를 해결하기 위해 async과 await가 등장하였다. function앞에 async를 붙이며 해당 함수는 항상 Promise를 반환한다. 이게 무슨 말인지 이해를 잘못했다. Promise를 단순히 이름으로 생각했는데 아니었고 JavaScript에 내장된 객체이다. 밑의 방법 1과 2는 같다.
// 방법 1
async function getData() {
  return "데이터";
}

// 방법 2
function getData() {
  return Promise.resolve("데이터");
}
따라서 Promise객체를 쓰지 않아도 Promise가 씌어져서 나온다. 그리고 이때 Promise의 결과값을 받는 것이 await이다. await를 쓰지 않으면 객체 그 자체가 반환이 되고 await를 써야 그 결과값이 반환되는 것이다.
