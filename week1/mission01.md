### React 기본개념

화면을 나누는 것에 대해 배웠다.

먼저 인스타그램 게시물을 분석하며, 화면을 보면서 Profile, PostImage, Actions, Content칸으로 구별하는 눈을 길렀다.

이를 Component라는 요소들로 분해하면 더 객체지향적으로 요소를 사용할 수 있다. Component를 쓸 때는, 항상 이름을 대문자로 초기화해야 한다.

또한, 이렇게 분리된 Component에 항상 고정된 값을 하드코딩할 순 없으니, 데이터를 보내어 계속 변하게 해야되는데 이렇게 보내는 데이터값은 Props라고 부른다. 즉, Component로 객체들을 나누어 이를 조합하여 화면을 구상하고, 그 Components 안의 값들은 Props를 전달하며 값을 바꾸는 것이다.

각 Component들을 잘 분리하였다면, 이를 조합하여 메인 페이지 구성 함수를 만들고, 마지막으로 배열에 데이터를 넣어 map을 이용해 그 배열 데이터와 '메인 페이지 구성 함수'를 이어주면 화면이 완성된다. 

마지막으로, map은 react가 아닌 javascript 문법이다.
