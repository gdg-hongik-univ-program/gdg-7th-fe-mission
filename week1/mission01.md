##오늘의 키워드 : component, props, array + map
---------------------------------
###component : 화면의 일부를 하나의 단위로 화면에서 찾은 구조를 코드에서도 표현하는 단위
- component 이름은 대문자로 시작
- jsx에서 태그처럼 사용 가능
- 같은 UI를 다시 사용하기 쉬워짐
----------------------------------
###props : component에 값을 전달하는 방법
- 보내기 -> 받기 -> 보여주기
- 구조는 component, 달라지는 값은 props
