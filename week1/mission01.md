오늘은 실습을 하면서 쭉 따라가는 것이 아닌 정답이 없이 혼자 해내야 하는 것들이 많아서 어려웠다.
새로운 용어가 많이 나오면 react여서 단순히 이름을 변수로 쓴 것과 javascript의 함수의 구분을 잘 해야 하는 것 같다.

구조를 알아보기 쉽게 묶어서 함수처럼 쓰는 것이 component, 사실상 덩어리짓고 이름을 부여하는 것 같다. 이때 첫자는 대문자로 써야한다.

compnent로 코드의 양을 줄여도 반복해서 쓰면 같은 자료밖에 반복해서 쓸 수 밖에 없다.
이때 구조를 남기고 안에 있는 값을 props를 통해 전달할 수 있다.
component가 다 모여있는 함수에 내가 기입하고 싶은 component뒤에다 <Post 이름="철수"/>의 형식으로 전달하면 그 componet(여기서는 Post)에서 철수를 받아온다.
이때 function Post(props)의 원래 이름이 있던 자리, "<>{철수}<>" -> {props.이름}형식으로 받아준다
이렇게 총 3부분이 관여가 된다. 
                        1.<Post 이름="철수">, <Post 이름="영미">
                2.function Post(props) 
                             3.{props.이름}
                              ={철수}, {영미}
약간 3단논법과 더하기를 섞은 느낌도 난다.
그래도 자료를 다르게 여러개를 나열할 수는 있지만 마찬가지로 코드도 반복해서 써야한다.
이때 구조까지 반복하는 것이 아닌 데이터만이 반복되는 특징을 살려 array라는 개념, map이라는 함수가 등장한다.
사실상 오늘 배운 함수는 map 하나밖에 없는 것 같다
array를 통해 내가 가지고 있는 데이터의 집합체를 만들고 - const 집합체s = [{데이터1:"철수", 데이터2:"1"},{데이터1:"영미"},,,];
함수의 return값에 <>{}<> jsx형식에서 중괄호 안에 - {집합체s.map((집합) => (....))}
...안에는 원래 <Post 이름="철수"> ---> <Post 이름={집합.데이터1}>
사실 집합체s가 하나 추가되면서 처음에 한번 거치는 설정이 추가되었을 뿐이지만 굉장히 어려운 것 같다
그리고 map이란 함수 자체가 if와 같은 조건도 없이 자기가 스스로 순회하는게 신기했다
    1.집합체s.map(집합)                          1.집합체s.map(집합)               
    2.<Post 이름={집합.데이터1}>                  2.<Post 숫자={집합.데이터2}>
    = <Post 이름="철수">,<Post 이름="영미">      = <Post 숫자="1">,<Post 숫자="2">
    3.function Post(props)                     3.function Post(props)
                 4.{props.이름}                              4.{props.숫자}
                 ={철수},{영미}                                       ={1},{2}
이떄 component뒤의 변수를 지정할때는 쉼표를 쓰지않는다.
