React : JavaScript 라이브러리

Component : React를 효율적으로 사용하기 위해서 사용하는 개념

DOM : HTML 태그 하나하나를 자바스크립트로 컨트롤할 수 있도록 만든 객체 체계

'트리 구조'로 만들어져 있으며, 각각의 태그간의 관계성, 객체들 간에 위계 구성이 존재한다.

흔히 HTML 코드가 너무 길어지는 것을 대비하기 위해서 JSX를 사용하는데, 여기서 JSX는 JavaScript Syntax Extension의 약자이다.

이번에 사용하는 gdg-project-shop 예시에서는?

<Navbar/>
<Content/>
<Footer/>

이렇게 콘텐츠를 나눈다면, 자원을 효율적으로 관리할 수 있으며, 길어진 코드를 나눠서 확인 및 유지보수가 가능하다.
