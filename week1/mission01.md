# React 기본 개념 학습하기

## 필요한 이유
여러 명이 작업을 했을 때 작업이 중복이 되서 비효율적인 경우가 있다
섞이지 않게 작업하는게 가능하겠지만 엄청 힘들 것이다
그래서 React가 등장한다. 

## DOM이란?
HTML을 브라우저가 읽게 만들고 자바스크립트로 통제하기 위한 트리 구조
문서를 재가공해서 뿌리기 위한 중간 매개체 느낌

## 예시: 기아 타이거즈 홈페이지
첫 요청에서 `<div>`태그 하나만 있는 html코드를 보내준다. 
그 다음에는 맨 윗줄부터 파싱하며 링크나 스크립트 태그에 있는 자바스크립트나 css파일을 가져온다. 
A는 헤더만 작업해~, B는 메인만 작업해~, C는 푸터만 작업해~ 이런식으로 분할 가능하다

## JS에 HTML 끼워넣기
HTML을 사용하지 않고 JS로 모든 화면을 동작할 수 있다. 
새로운 태그를 만들고, 태그에 데이터를 넣고,
새로운 태그를 HTML에 추가하고, HTML을 화면에 업데이트한다

## JS에 HTML 넣는 방법
JS 코드 양이 너무 많다-> JS에 HTML을 넣자

자바스크립트에 HTML을 넣어서 만들고 원래의 긴 코드로 바꿔주는 번역기(컴파일러)를 만들자
-> JSX(문법) + 바벨(라이브러리)

태그 안에 JS 컴포넌트를 때려넣는 방법: React

## React 파일명 
컴포넌트는 함수명, 파일명은 대문자로 해야한다
기존 HTML이 소문자로 시작해서 대문자로 구분을 준다

## SPA
SPA: 한 페이지에 하나의 정보를 담을 필요 없이 하나의 앱처럼 동작함

SPA 라이브러리 중 가장 점유율 높은 것: React

## 컴포넌트
화면의 일부분을 담당하는 재사용 가능한 조각이다. 

React에서는 JSX를 반환하는 함수로 만든다. 

```jsx
function MyButton() {
  return <button>민형님 안녕하세요</button>;
}
```
버튼, 프로필, 카드처럼 화면을 레고 블록처럼 쪼개서 만든다. 

한번 만들어 두면 여러 번 재사용할 수 있다. 

### 사용하기

`<Mybutton />`을 쓸 때마다 같은 모양의 버튼이 나온다. 

컴포넌트 안에 컴포넌트를 넣을 수 있다. 

컴포넌트를 다른 파일에서 쓰려면 `export`로 내보내고 `import`로 가져와야 한다.
