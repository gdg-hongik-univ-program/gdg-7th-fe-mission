# 1. JavaScript에서 let과 const의 차이점은 무엇인가요? const로 선언한 객체의 속성도 변경할 수 없을까요?
let은 변수에 새로운 값을 재할당 가능하지만 const에는 재할당이 불가능하다. const로 선언한 객체의 속성은 변경 할 수 있다.

# 2. 배열의 map(), filter(), find()는 각각 어떤 역할을 하며, 반환하는 결과는 어떻게 다른가요?
## map()
- 호출한 배열의 모든 요소에 주어진 함수를 호출한 결과로 채운 새로운 배열 생성
- 반환값 : 새 배열을 반환, 길이는 원래 배열과 같음
## filter()
- 주어진 배열의 일부에 대한 얕은 복사본을 생성하고, 주어진 배열에서 제공된 함수에 의해 구현된 테스트를 통과한 요소
- 주어진 배열에서 테스트를 통과한 요소만 포함하는 해당 배열의 얕은 복사본 배열 반환, 테스트를 통과한 요소가 없을 경우 빈 배열 반환
## find()
- 제공된 배열에서 제공된 테스트 함수를 만족하는 첫 번째 요소를 반환
- 테스트 함수를 만족하는 값이 없으면 undefined 반환

# 3. 구조 분해 할당(Destructuring)은 무엇이며, 어떤 상황에서 활용할 수 있나요?
- 배열이나 객체에서 필요한 값을 꺼내 변수에 할당
## 배열과 객체에서의 구조 분해 할당 차이
- 배열은 대괄호를 사용하고 객체는 중괄호를 사용한다.
## 값을 꺼내는 순서와 속성 이름의 차이
- 배열은 순서로 꺼내고 객체는 속성 이름으로 꺼낸다. 
## 구조분해할당을 사용하는 이유
- 코드가 짧고 읽기가 쉬워진다. 기본값을 줄 수 있다. 함수 매개변수에서 바로 꺼낼 수 있다. 두 변수의 값을 쉽게 바꿀 수 있다.
------------------------------------------------------------------------------
# 변수와 자료형
변수 : 프로그램에서 사용하는 값을 저장하고 참조하기 위한 이름
- let : 변수에 새로운 값을 재할당 가능
- const : 선언할 때 값을 할당, 재할당 불가
자료형
- typeof : 값의 자료형을 확인 할 수 있는 연산자
- 원시 타입 : 문자, 숫자, boolean
- 객체 타입 : 객체, 배열, 함수
-------------------------------------------------------------------------------
# 배열과 객체
- 배열 : 여러 개의 값을 순서대로 저장할 수 있는 자료구조
- 객체 : 여러 데이터를 key와 value의 형태로 표현
------------------------------------------------------------------------------
# React에서 자주 사용하는 JS문법
- 템플릿 리터럴 : 백틱을 사용해 문자열 작성, 문자열 안에 변수나 표현식 넣을 수 있다.
- 삼항 연산자 : 조건에 따라 다른 값을 반환할 때 사용
- 조건 ? 참일때 값 : 거짓일 때 값
- 구조분해 할당은 위에 설명
- 전개 구문 : '...'을 사용하여 배열의 요소나 속성을 펼치는 문법
- export : 다른 파일에서 사용할 값 내보내기
- import : 해당 값 가져오기
