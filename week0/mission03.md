1. 변수를 선언할때 let과 const를 사용하는데 이때, let은 변수에 새로운 값을 재할당할 수 있고, const는 선언할 때 값을 할당해야 하며, 이후 재할당할 수 없다. 또한 let은 선언 시 초기화가 생략 가능한 대신 const는 선언 시 초기화가 필수이다. const는 값을 재할당 할 수 없지만 배열,객체의 내부 값은 바꿀 수 있다. 값이 아닌 참조(주소)를 고정하기 때문이다.
2. map은 반환값이 각 요소를 반환하는 대신 fileter와 find는 true와 false값을 반환한다. 그렇기 때문에 map은 각 요소를 반환하는 대신, filter은 true인 값의 배열, find는 요소가 있을 경우 true인 요소 하나를 반환한다. 이때 세 함수 모두 원본 배열에는 변화가 없다.
3. 구조 분해 할당은 객체 안의 값을 꺼내서 변수에 바로 담는 방법이다. 배열에서는 []를 통해 객체에서는 {}통해 표현한다. 이때 배열에서는 순서를 통해 꺼내고 객체에서는 속성 이름을 통해 꺼낸다.
배열에서는 순서가 전부다. 변수 이름은 상관이 없다.
반대로 객체에서는 이름이 전부다. 순서는 상관이 없다. 따라서 객체는 속성의 개수와 키의 개수가 맞지 않을 수도 있으며 뒤에 있는 키를 먼저 써도 되고 심지어 키의 이름을 새로 지정할 수도 있다.
이러한 구조분해할당을 쓰면 원소를 하나하나 나열하는 것이 아닌 배열의 형태로 한번에 정의할 수 있어 코드가 짧고 읽기 쉬워진다. 또한 변수 값 교환이 편리해지고 여러 값을 반환할 때 편리해진다. 값을 교환할때 오른쪽이 먼저 복사되기 때문에 꼬이지 않고 한꺼번에 진행된다.
