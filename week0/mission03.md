JavaScript

1. let은 변수 선언으로 값이 바뀔 수 있고, const는 상수 선언으로 값이 바뀔 수 없습니다
const여도 이것으로 만든 배열이나 객체 안의 값은 바꿀 수 있습니다. 변수에 다른 배열이나 객체를 통째로 바꾸지를 못하는 거죠
변수는 배열이나 객체에서 겉 껍데기 같은 겁니다

2. map(): 모든 요소를 바꿔서 새 배열을 만듦
	모든 값에 같은 작업을 할 떄 사용
	반환값: 새 배열, 길이는 원본과 항상 같다

filter(): 조건에 맞는 것만 골라 새 배열을 만듦
	일부만 골라만들때 사용
	반환값: 새 배열, 길이는 원본보다 짧거나 같음, 하나도 없으면 빈 배열
	
find(): 조건에 맞는 첫번째 하나만 찾는다
	딱 하나를 찾을 때 사용
	반환값: 요소 하나, 못 찾으면 undefined

3. 구조 분해 할당: 배열이나 객체에 들어 있는 값을 꺼내서 여러 변수에 한 번에 담는 문법, 배열은 [ ]로 순서대로, 객체는 { }로 속성 이름에 맞춰 꺼내기
객체에서 필요한 값만 꺼낼 때: user.name, user.age를 반복하지 않고 const {name, age}  = user; 이렇게 한 번에 끝냄, 함수 매개변수로 객체를 받을 때, 함수가 배열을 돌려줄 때, 값이 없을 때 기본 값을 정할 때, 두 변수가 값을 바꿀 때

class: 비슷한 객체를 여러 개 찍어낼 수 잇는 설계도, 이 틀이 class이고 찍혀 나온 것이 인스턴스(객체)
class를 통해 항상 똑같은 객체를 쉽게 만들 수 있다
상속을 통해 class를 물려 받아 기존 틀에 기능을 조금 더한 새 틀을 만들 수 잇다
