# css : HTML로 작성한 웹페이지의 디자인과 레이아웃을 지정하는 스타일 언어
- 요소들의 색상, 크기, 위치 등을 결정
- 선택자 : 어떤 HTML 요소에 스타일을 적용할지 지정하는 역할
- 우선순위 : ID 선택자 > 클래스 선택자 > 태그 선택자
- CSS의 추가적인 주요 속성 : font-family -> 글꼴 / text-align -> 정렬 등

# flexbox : 웹페이지에서 여러 요소를 효율적으로 정렬하고 배치할 수 있도록 도와주는 css레이아웃 방식
## flex container :  Items를 감싸는 부모 요소
- display:flex --> flex container를 정의(수직 쌓임)
- flex-direction : Items의 주 축(main-axis)을 설정
- flex-wrap : Items의 여러 줄 묶음(줄 바꿈) 설정, 기본값은 nowrap
- 주축 : 요소들이 줄 서는 방향
- 교차축 : 주축과 수직인 방향
- justify-content : 주 축(main-axis)의 정렬 방법을 설정
- align-items : 교차축의 정렬 방법. 단, items가 한 줄 일 때
- gap : 각 아이템 사이의 간격을 설정
## flex items : flex container의 안쪽, 자식 요소

# 1. CSS의 id 선택자와 class 선택자는 어떻게 다르며, 각각 어떤 상황에서 사용하는 것이 좋을까요?
CSS의 id 선택자는 #notice로 표현되며 고유한 ID를 가진 요소에 적용된다. class 선택자는 .description으로 표현되며 같은 클래스를 가진 여러 요소에 적용 가능하다.
class를 기본으로 쓴다. 다시 쓰기 쉽고, 우선순위가 낮기 때문에 충돌이 덜 생기기 때문이다. id 선택자는 딱 하나를 찾아야 할 때 쓴다.

# 2. margin과 padding은 어떤 차이가 있나요? box-sizing: border-box를 사용하면 무엇이 달라질까요?
margin은 요소 바깥쪽 공간을, padding은 요소 내부의 공간을 조절한다. box-sizing: border-box을 사용하면 설정한 width 안에 Padding과 Border를 포함하도록 계산한다.
