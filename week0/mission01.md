# 1. HTML의 Element와 Attribute는 무엇인가요?
Element(요소) : 시작 태그 + 콘텐츠 + 종료 태그
- 빈 요소 : 콘텐츠를 포함하지 않고 종료태그를 사용하지 않는 요소
Attribute(속성) : 요소에 추가적인 정보를 제공함
- <이름 = "값"> 형태 
-------------------------------------------------------------
# 2. div와 Semantic Tag의 차이는 무엇인가요?
div는 특별한 의미를 부여하지 않고 요소들을 묶는데 사용하는 태그이다. 하지만 Semantic Tag는 태그의 이름만 보고도 어떤 역할과 의미를 가지는지 명확하게 알 수 있다.
-------------------------------------------------------------
# 3. <article> vs <section> 두 태그의 차이점은 무엇인가요?
<article> : 혼자서도 완성된 글
<section> : 큰 내용 안의 한 구역
<article>은 이 페이지가 아닌 다른 페이지 안에서도 의미가 있고 <section>은 <section>이 있는 페이지 안에서만 의미가 있다.
