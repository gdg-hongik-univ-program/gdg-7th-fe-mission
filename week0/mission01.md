HTML

1. Html이란

웹페이지의 뼈대
각 페이지 어떤 요소로 구성을 정의

HyperText Markup Language

HyperText: 하이퍼 링크로 다른 문서나 웹페이지로 이동 가능한 텍스트
Markup Language: 태그 등을 활용하여 문서의 구조와 의미 표현하는 언어
(not 프로그래밍 언어, 마크업 언어임)



2. HTML문서의 기본 구조

head: 문서 정보를 담음
body: 실제 콘텐츠 담음

<!DOCTYPE html>: HTML문서임을 알리고 표준 모드로 해석하도록 하는 선언
<html>: HTML문서의 최상위 요소
<head>: 문서의 설정 및 메타데이터
<body>: 실제 웹페이지의 콘텐츠

<html lang="ko">에서 lang="ko"는 문서의 기본 언어가 한국어

-head에 들어가는 주요 태그
meta: 문자 인코딩, 화면 설정, 문서 설명 등
title: 브라우저 탭에 표시되는 제목
link: 외부 CSS 파일 등 리소스 연결
style: HTML문서 내부네 CSS 작성
script: JavaScript 코드 작성 또는 외부 파일 연결

body에는 제목, 문단, 이미지, 버튼과 같은 사용자가 실제로 보는 콘텐츠



3. HTML의 기본 문법

3.1 요소(Element), 태그(Tag)

HTML문서는 여러 요소(element)로 구성

<p>안녕하세요!</p>

<p>: 시작 태그
안녕하세요: 콘텐츠
</p>: 종료 태그
(이 셋이 일반적인 구성임 
but, 모든 요소가 종료 태그가 필요한 것은 아님
빈 요소(void Element)는 종료 태그 미사용)

3.2 요소의 중첩 관계

<div>
  <h2>상품 정보</h2>
  <p>상품에 대한 설명입니다.</p>
</div>

<h2>, <p>: 자식 요소
<div>: 부모 요소

3.3 속성(Attribute)

요소에 추가적인 정보 제공를 제공하기 위해 속성(Attitude)을 지정할 수 있다

<img src="product.png" alt="흰색 반팔 티셔츠" />

scr와 alt가 속성에 해당
일반적으로 시작 태그 안에 이름="값" 형태로 작성

-자주 사용하는 속성
id 요소를 식별하기 위한 고유한 값(한 문서에서 고유하게 지정)
class 요소를 그룹화하거나 스타일을 적용할 때 사용(여러 요소에서 같은 값을 사용 가능)
src 이미지 등 리소스의 경로
href 링크가 이동할 주소
alt 이미지의 내용을 전달하는 대체 택스트
title 요소에 대한 추가 정보
style 요소에 직접 CSS 스타일 적용

3.4 HTML 주석

<!--와  --> 사이는 주석 처리



4. 자주 사용하는 HTML 태그

h1~h6: 제목과 하위 제목(숫자가 작을수록 상위 수준의 제목)
p: 문단
span: 의미를 별도로 부여하지 않는 인라인 컨테이너
strong: 중요한 내용
em: 강조하는 내용
br: 줄바꿈
hr: 주제나 문단 사이의 구분



5. 시맨틱 HTML(Semantic HTML)

<div> 태그로만 영역을 구분하려고 하면 
-각 영역의 역할을 파악하기 어려움 -> 코드 가독성, 유지보수성 하락
-검색엔진 최적화(SEO)에 불리할 수 있음
-웹 접근성 측면 한계 -> 스크린 리더 사용자가 주요 영역을 구분하고 탐색하기 어려움

5.1 시맨틱(Semantic)이란?

시맨틱은 의미론적인, 의미를 가지는이라는 뜻
어떤 이름과 역할을 통해 콘텐츠가 어떤 의미를 가지는지 표현 가능

의미를 명확하게 하는 HTML요소를 시맨틱 요소

5.2 대표적인 시맨틱 태그

header: 페이지 또는 특정 영역의 머리말
nav: 주요 탐색 링크 영역
main: 페이지의 중심 컨텐츠
section: 주제별 콘텐츠 구획
article: 독립적으로 구성되는 컨텐츠
aside: 주요 컨텐츠와 간접적으로 관련된 내용
footer: 페이지 또는 특정 영역의 바닥글

    1. Element와 Attribute 차이
        Element(요소)
        HTML 구성하는 기본 단위, 시작태그 + 콘텐츠 + 종료 태그로 보통 구성된다. 
        빈 요소(Void Element)는 종료 태그가 없다
        요소 안에 요소가 들어 갈 수 있다.(부모 요소, 자식 요소)

        Attribute(속성)
        Element에 추가 정보를 주는 것, 시작 태그 안에 '이름="값"' 형태

    2. div와 Semantic Tag의 차이
        div
        구분이 없어 이름만으로는 역할을 알 수가 없다.
        SEO에 불리하며 스크린 리더가 영역을 구분하기 어렵다

        Semantic Tag
        영역의 역할을 이름으로 정함
        가독성 유지보수가 쉽다. 코드만 봐도 구조가 보이기 때문에
        SEO에서  검색엔진이 핵심 콘텐츠 파악이 쉽다
        스크린 리더로 주요 영역 사이를 바로 이동할 수 있다

    3. <article>과 <section>의 차이
        <article>: 그 부분만 떼어내도 끝나는 독립적인 콘텐츠

        <section>: 문서 안에서 주제 별로 나눈 구획, 혼자 완결X (보통 제목 h2~h6를 함께 사용)
        <article>안에 <section>이 들어갈 수 있다
