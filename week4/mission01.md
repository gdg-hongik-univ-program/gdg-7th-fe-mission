# Refactoring
의미 : 프로그램의 겉보기 동작(외부 기능)은 유지한 채, 내부 구조를 더 이해하기 쉽고 유지보수하기 좋게 수정하는 작업
목적 : 중복, 복잡성, 결합을 줄이고 의도를 드러내며 변경비용 낮추기
장점
- 버그를 찾고 해결하기 쉬움
- 새 기능 더 빨리 추가 가능
- 협업에 필요
----------------------
# Custom Hook
React의 Hook 기능을 재사용 가능한 로직으로 캡슐화한 함수

## 특징
- 일반 함수처럼 생긴 React Hook
- 이름이 use로 시작
- 데이터를 캡슐화하거나 특정 동작을 쉽게 재사용하도록 설계

## 사용목적
- 같은 로직을 여러번 사용하지 않기 위해
- 수정할 곳을 한 곳으로 모으기 위해
- 컴포넌트를 짧고 읽기 쉽게 하기 위해
-----------------
# 일반함수와 Custom Hook의 차이
- 일반 함수 안에서는 hook 사용이 불가능하지만 Custom Hook 안에서는 사용이 가능하다.
-------------------
# 내 코드에서 리팩토링 하거나 custom hook 사용해보기
지금 나의 쇼핑몰 코드에서는 Content, CategoryPage, PricePage, SortPage가 모두 똑같은 코드를 사용하고 있다. 
```
<ProductList items={filteredItems} cart={cart} onAddToCart={onAddToCart} />
```
이렇게 고친다면 Item에 props를 하나 추가하고 싶을 때, 4개 부분을 고치는게 아니라 1개 부분만 고치면 된다.
