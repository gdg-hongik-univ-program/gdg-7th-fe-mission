React Router

react router를 쓰기 이전에는 원래 페이지 전체를 새로고침을 했어야 하는데 이를 더 효율적으로 하기 위해서 특정 컴포넌트만 바꿔서 그대로 사용하는 것을 react router이라고 합니다
BrowserRouter로 앱 전체를 감싸야 라우터 기능을 쓸 수 있습니다. 
Route는 특정 주소이면 특정 컴포넌트를 보여 주라는 것이고 Routes는 Route의 묶음으로 그 주소와 맞는 것 하나를 골라서 그 자리에 보여주는 것입니다.
Link를 사용하면 전체 새로고침을 안해도 되게 됩니다. Link사용 시 React Router가 대신 옮겨 줍니다
useNavigate는 어떤 일이 끝났을 때 코드가 알아서 이동시켜집니다. 




일반 CSS, CSS Modules, TailWind CSS 차이 비교

일반 CSS는 그냥 CSS문법 그자체입니다. HTML/JSX가 깔끔하다는 장점이 있습니다. 
하지만 이름 충돌의 위험이 있고 프로젝트가 커지면 당연히 이름을 짓는데 힘들어집니다. 또 다른 CSS와는 다르게 어떤 CSS가 아직 쓰이는지, 지워도 되는지 파악하기 어렵습니다.

CSS Modules는 일반 버전과 거의 똑같으나 다른 점은 파일을 ~.module.css로 지은 후 사용합니다. 파일 이름을 ~.  module.css로 지으면 빌드 도구가 CSS Module로 인식합니다. 
Import하면 원래의 클래스의 이름을 키로, 바뀐 이름을 값으로 가진 자바 객체가 반환된다. JSX에서는 이 객체의 값을 className에 넣는다. className={styles.이름} 형식으로 씁니다. 클래스 이름이 파일 단위로 격리되니 다른 파일과 이름이 겹쳐도 충돌하지 않습니다.

Tailwind CSS는 CSS파일 없이 className에 바로 사용합니다. CSS를 직접 쓰지 않고 그 클라스들을 골라서 조합만 한 것입니다. 그니까 미리 줄임말들을 만들어 놓은 것이죠. 파일을 왔다 갔다도 안해도 되고 클라스 이름 지을 고민이도 없고 충돌도 없습니다. 그리고 최종적으로 사용한 클래스만 최종CSS에 들어가기 때문에 파일의 크기가 작습니다. 하지만 이 줄임말들을 외워야 한다는 단점이 있고 설치 및 설정을 해야한다는 단점도 있습니다.
