# React router
-----------------------------------------
## SPA(Single Page Application)
서버로부터 새로운 페이지를 불러오지 않고 현재의 페이지를 동적으로 다시 작성함으로써 사용자와 소통하는 웹 애플리케이션이나 웹 사이트
- 라우팅 : 어떤 화면에서 다른 화면으로 화면을 전환하는 내비게이션을 관리하기 위한 기능
- 클라이언트 사이드 라우팅 :  브라우저가 서버에 전체 페이지를 요청하지 않고, 자바스크립트가 브라우저 내부에서 URL 변경을 감지해 화면을 전환하는 방식
--------------------------------
## Browserrouter
HTML5의 History API(pushState, replaceState, popstate event)를 사용하여 URL과 UI를 동기해주는 Router
- 페이지를 새로 고침을 하지 않고도 주소 변경 가능
- 현재 주소에 관련된 정보를 props로 조회 및 사용이 가능
-----------------
## Route : path에 따라 해당 UI를 보여주는 라우팅 기능을 가진 컴포넌트
```
<Route path="/이동할 주소">
	<출력할 컴포넌트 />
<Route/>
```
----------------------------

## 일반 CSS와 CSS Modules, Tailwind CSS의 차이

### 일반 CSS
- 작성 위치 : .css
- 적용 범위 : 프로젝트 전체
- 장점 : 가장 기본적이고 배우기 쉬움
- 단점 : 프로젝트가 커지면 관리가 어려움

### CSS Modules
- 작성 위치 : .module.css
- 적용 범위 : 불러온 컴포넌트
- 장점 : css 그대로 쓰면서 충돌을 막음
- 단점 : 파일이 늘어남

### Tailwind CSS
- 작성 위치 : JSX의 className
- 적용 범위 : 클래스를 쓴 태그만
- 장점 : 파일을 오가지 않고 빠르게 작성
- 단점 : className이 길어지고 클래스 이름을 익혀야함
