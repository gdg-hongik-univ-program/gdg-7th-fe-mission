# Mission 01. Props와 State 이해하기
---------------------------------------
## Props란?
상위 컴포넌트가 하위 컴포넌트에 값을 전달할 때 사용하는 속성
### props 특징
- 단방향 데이터 흐름 : 상위 컴포넌트 --> 하위 컴포넌트
- 부모 컴포넌트 수정 가능, 자식 컴포넌트 읽기만 가능
--------------------------------------
## state란?
컴포넌트가 스스로 기억하고 바꿀 수 있는 값
----------------------------------------------------------------------------
## component의 생애 3단계
1. Mount : 컴포넌트가 화면에 추가될 때
2. Update : 컴포넌트가 일반정으로 상호작용에 대한 응답으로 새로운 props나 state를 수신할 때
3. Unmount : 컴포넌트가 화면에서 제거 될 때
---------------------------------------------------------------------
# React Hooks
## Hook 장점
1. 코드 재사용성과 관심사 분리
2. 상태 로직 단순화
3. 사이드 이펙트 감소
----------------------------------------------------------
## useState : 컴포넌트의 상태 관리
const [state, setState] = useState(initialState);
initialState : 상태 초기 값
---------------------------------------------------
## useEffect : 외부 시스템과 컴포넌트를 동기화
컴포넌트가 mount unmount update 되었을 때 특정 작업을 실행
useEffect(callback, dependencyArray);
[] : 의존성 배열, 이 코드를 언제 다시 실행할 지 정함
[count] : 처음 한 번, count가 바뀔 때마다
생략 : 화면을 다시 그릴 때 마다
------------------------------------------------
## useNavigate : 코드로 페이지 이동하기
어떤 일이 끝나고 이동해야 할 때 사용
import { useNavigate } from "react-router-dom";
